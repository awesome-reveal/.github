# Get help

- Read the guides and the API reference at [awesome-reveal.dev](https://awesome-reveal.dev).
- Ask a question or suggest a feature in [GitHub Discussions](https://github.com/awesome-reveal/awesome-reveal/discussions).
- Report a bug in the [issues](https://github.com/awesome-reveal/awesome-reveal/issues/new/choose) of the packages repo. Include a minimal reproduction.
- Report a vulnerability as the [security policy](SECURITY.md) tells you. Do not open a public issue for it.
